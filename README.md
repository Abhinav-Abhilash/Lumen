# Lumen Studio

A practice website I made while learning HTML and CSS. It is a training project for a fictional design studio called "Lumen Studio", built with plain HTML and CSS only (no JavaScript).

The images, icons and text were generated with the help of Claude (Anthropic). I used them as assets to practise building a full page.

## What I practised

- HTML page structure and semantic tags
- CSS Grid and Flexbox layouts
- CSS variables (design tokens)
- Responsive design and dark/light mode
- Hover effects, animations and a mobile menu with no JavaScript

## Project structure

```
index.html      main page
css/
  tokens.css    colours, font sizes, spacing
  style.css     page layout and styling
assets/         SVG logo, icons and images
copy.md         all the text used on the site
```

## How to run

1. Download or clone this repo.
2. Open the folder in VS Code.
3. Start a local server (for example, the "Live Server" extension), then open `index.html`.

A local server is needed so the icons load properly.
